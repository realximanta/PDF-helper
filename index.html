Privacy by design

The permission it doesn't have.

Most "free" PDF sites ask you to upload a file, run it through their server, and hand it back. Even if they mean well, your document made a round trip through someone else's disk.

PDF Helper has <uses-permission android:name="android.permission.INTERNET" /> removed from the manifest. Android itself will kill the process if any library ever tries to open a socket. The privacy claim is enforced by the OS, not by a policy page.

  • No analytics SDKs
  • No crash reporters
  • No storage permissions either — uses Android's scoped Storage Access Framework
  • Auditable source — read every line on GitHub
AndroidManifest.xml
<!-- No INTERNET permission on purpose. -->
<!-- Every PDF operation runs on-device. -->
<manifest xmlns:android="...">
  <application
      android:name=".PdfHelperApp"
      android:allowBackup="false">
    …
  </application>
</manifest>

Frequently asked

How is this really free? What's the catch?

There is no catch. The app runs entirely on your device, so there are no server bills to cover. The source is MIT-licensed on GitHub. There's no advertising because there's no network permission to load an ad.

Why isn't it on the Play Store?

Play Store distribution adds a proprietary signing layer and a 30% cut of anything paid. Releasing signed APKs straight from GitHub keeps the whole pipeline open and auditable — you can rebuild the exact APK from the tag.

What Android versions are supported?

Android 8.0 (API 26) and newer. That covers roughly 96% of active Android devices.

Does it work offline?

Yes — permanently. The app has no network permission, so every tool works with airplane mode enabled. If it did need a network, it would fail.

Can I edit the text inside an existing PDF?

Phase 1 (current) lets you add new text or images on top of any page. In-place editing of existing text, matching the original font, is on the roadmap for Phase 2 — it's a genuinely hard problem in the PDF format, so it deserves to be done well rather than shipped half-broken.

What happens if I open a signed PDF in the app?

Any modification — including removing a password — saves the document as new bytes, which invalidates the original digital signature. The app tells you this before you apply the change. If you need the original signed PDF, keep the source file untouched.

Is the source code public?

Yes — MIT-licensed on github.com/realximanta/PDF-helper. Fork it, change the icon, ship your own version. That's the whole point.
